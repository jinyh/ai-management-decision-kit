# 销售、客户与服务路径

适合销售、市场、客户成功、零售、电商和服务运营岗位。

## 建议顺序

1. [任务与经营结果](../cards/01-task-and-outcome.md)：明确获客、转化、留存或服务结果。
2. [上下文与企业知识](../cards/04-context-and-enterprise-knowledge.md)：区分客户记录、产品政策和当前沟通。
3. [主动检索](../cards/05-active-retrieval.md)：让建议保留产品、合同和服务规则来源。
4. [工具与权限](../cards/08-tools-protocols-and-permissions.md)：分开读取客户信息、生成建议和实际发送。
5. [人工授权与恢复](../cards/09-human-authorization-and-recovery.md)：处理退款、折扣、承诺和投诉升级。

## 完成标志

能够说明AI可以准备什么、可以直接完成什么、哪些承诺必须由责任人批准。

建议从[退款与补偿案例](../cases/customer-refund.md)开始，并运行 `/diagnose 客户退款与补偿`。
