# 2026-09 AI能力基线

> 观察与核验日期：2026-09-08。计划于2026-09-18再次核验。以下内容只说明能力方向和开放边界，不构成模型排名或采购建议。

近期官方发布共同显示四个方向：模型可以处理更长、更复杂的专业任务；工具调用和计算机操作能力继续增强；Agent需要保存状态并在运行中接受修正；企业检索开始从一次相似度查询扩展为问题拆解、多源检索、重排和来源保留。

管理含义不是“模型已经可以完全接管流程”，而是管理对象从一次回答扩展为完整运行：上下文、企业知识、工具权限、运行记录、评测和人工责任必须共同设计。
