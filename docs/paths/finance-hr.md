# 财务、人力与公司职能路径

适合财务、内控、人力、法务、公司事务和行政岗位。

## 建议顺序

1. [任务与经营结果](../cards/01-task-and-outcome.md)：明确决策准备、核对、审查或服务任务。
2. [任务型数据质量](../cards/02-task-data-quality.md)：检查来源、有效期、口径和可追溯性。
3. [上下文与企业知识](../cards/04-context-and-enterprise-knowledge.md)：区分制度、合同、个人记录和当前材料。
4. [工具与权限](../cards/08-tools-protocols-and-permissions.md)：限制敏感字段、对象和外部发送。
5. [四层评测](../cards/10-four-layer-evaluation.md)：增加合规、偏差、审计和人工复核指标。

## 完成标志

能够用最少必要数据支持一个决定，并说明保存、访问、复核和删除责任。

建议运行 `/knowledge 你的核对或审批准备任务`。使用真实任务时只提供脱敏结构，不粘贴个人档案、薪酬、合同或财务明细。
