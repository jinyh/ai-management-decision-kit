# 智能体循环与任务状态

## 管理结论

智能体适合目标明确、路径需要根据环境调整、能够检查中间结果的多步任务。步骤固定、异常少、规则清楚的流程，普通自动化通常更容易控制。

## 完整工作循环

获取信息 → 规划步骤 → 调用工具 → 检查结果 → 处理失败 → 保存状态 → 继续、停止或请求人工决定。

真正需要管理的是整个运行过程：它读了什么、调用了什么、结果是否通过检查、失败后保存了什么状态、由谁批准继续。

## 三项边界

- 记住上一步，不等于获准做下一步。
- 能调用工具，不等于可以调用所有参数和对象。
- 自动重试不等于恢复；环境、凭据或输入受到污染时应先隔离和接管。

## 选择题

如果任务只有三步、规则稳定、每一步都可以确定验证，为什么还需要智能体？先回答这个问题，再讨论模型。

关联：[工具、协议与权限](08-tools-protocols-and-permissions.md)｜[人工授权与恢复](09-human-authorization-and-recovery.md)

## 模型选择与程序控制

模型依据当前证据提出下一工具调用；程序检查输入类型、对象范围和当前授权，执行后保存工具结果与检查点。任务状态、企业外部事实、授权状态分开维护。说明机制时展示可观察的工具输入输出与选择依据即可。

超时表示本地未收到结果，外部交易可能已经完成。先按请求标识核对：已创建则使用原回执；确认未创建且当前授权有效才考虑重试；持续未知则人工接管。外部服务必须支持同一业务请求的幂等去重，仅在本地记录一个编号不够。撤权应阻断后续调用，但不会自动撤销已经完成的外部交易。

简化串行算例：每一步在此前步骤成功条件下的成功率均为95%，十步且无重试时，整体约为0.95的10次方，即59.9%。条件概率连乘不要求独立，但不能未经检验就把十个边际成功率代入。

研究机制依据：[ReAct，2022](https://arxiv.org/abs/2210.03629)。持久化、授权与恢复是课程的企业系统设计归纳。

## 数据与学习的边界

运行中的“观察—行动—反馈”可以只执行既定策略；强化学习还要用奖励更新策略或行动回报估计，以改善后续行动。调用工具一次并不等于完成学习。参见[C15 强化学习、环境与奖励](15-reinforcement-learning-environments-rewards.md)。

## 系统从经验中改善的三种方式

| 要改变什么 | 如何改善 | 应检查什么 |
|---|---|---|
| 业务事实与制度知识 | 修订知识库、检索索引及有效版本 | 事实是否生效、引用是否正确 |
| 可复用的经验与技能 | 审核执行轨迹，把成功方法和失败教训整理为可检索的操作手册 | 经验适用条件、反例、责任人、有效期与回滚 |
| 模型参数与行动策略 | 用审核示范、偏好或环境奖励训练 | 独立任务表现、原有能力回归、成本及授权边界 |

后两者都可能改变后续行为，但只有第三种明确更新模型参数或所训练的策略。把一条经验放进提示词，不等于模型已经完成参数训练。经验记忆也不能授予新的业务权限。

ACE研究用生成、反思与整理来更新上下文操作手册。它支持“改进上下文也是一种适应方式”，不代表所有企业应用都会自动持续学习。采购时要求供应商指出究竟更新了哪一层，并给出版本、审核和恢复办法。

自测：合同金额上限改变、工具失败后的恢复经验、持续遗漏必要步骤，分别优先改哪一层？什么证据能证明改动有效？

来源：[ACE](https://arxiv.org/abs/2510.04618)，2025年首次发布、2026年3月修订；新增内容核验2026-09-18。关联：[C04 企业知识](04-context-and-enterprise-knowledge.md)、[C14 训练数据](14-synthetic-data-demonstrations-preferences.md)。

## 运行循环与学习循环

[ReAct](https://arxiv.org/abs/2210.03629)于2022年发布、ICLR 2023发表，说明推理、行动、观察如何交替。企业另加权限检查与运行记录。一次运行通常改变当前上下文与任务状态；强化学习训练则依据奖励更新行动价值估计或策略。工具调用成功本身不能证明模型已学习。

重试使用同一业务请求编号，由服务端识别并阻止重复执行（幂等）。未知交易先核对外部结果，不能直接重发或假定失败。另需环境与凭据隔离，任务授权不能替代基础设施安全。

## 工作流与智能体的区别（P59）

固定工作流由程序预先规定下一步；智能体由模型根据目标与刚取得的结果选择下一步。二者都能调用相同工具，也都需要权限和结果检查。例如固定流程依次查合同、查物流、输出表格；智能体发现合同版本冲突后，可能先补查生效条款。选择空间越大，越要检查停止、接管与恢复条件。
