# 前沿内容说明

本目录记录会随时间变化的模型、Agent、企业知识和连接能力。稳定管理方法保存在 `docs/cards/`，不得因为厂商发布更新而频繁改写。

使用前沿事实时：

1. 查看事实卡的观察日期和适用范围。
2. 优先打开官方发布、模型卡或正式技术文档。
3. 区分正式开放、有限开放和预览能力。
4. 不根据模型榜单直接推断企业任务结果或ROI。
5. 需要当前结论时重新核验，并写明核验日期。
