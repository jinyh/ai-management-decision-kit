学生使用指南

不安装工具也可以学习

从 knowledge.md 选择角色路径，阅读一张知识卡，再填写一个模板。也可以把整个文件夹交给任何获企业允许、能够读取本地文件的Agent，并请它先阅读 AGENTS.md。

第一次建议完成以下闭环：

  1. 选择一个不含企业敏感信息的工作流。
  2. 先填写任务名称、经营结果和当前做法。
  3. 让Agent只推荐两到三张知识卡。
  4. 回答Agent的问题并修订一次初步判断。
  5. 保存一份投资备忘录或行动授权表。

使用OpenCode

  1. 根据OpenCode官方文档在个人电脑安装OpenCode。
  2. 解压本知识库并进入根目录。
  3. 在OpenCode中连接自己获准使用的模型提供商；不要把API Key写入仓库文件。
  4. 在根目录运行 opencode .。
  5. 输入 /diagnose 任务名称。OpenCode应能发现 ai-management-decision-coach skill和五个课程命令。

本仓库配置为只读学习模式：Agent不能编辑文件或运行命令，联网需要你再次同意，会话分享默认关闭。需要保存结果时，请从对话复制到自己的安全文档。

没有正常加载时

  • 确认当前目录是本知识库根目录，能够看到 knowledge.md。
  • 确认Skill文件位于 .agents/skills/ai-management-decision-coach/SKILL.md。
  • 退出并重新启动OpenCode，使新的项目配置生效。
  • 仍无法发现时，可以直接要求Agent阅读上述Skill文件；核心学习内容不依赖某一个工具。

企业信息保护

将真实信息改写成角色、区间和合成数据。例如，把企业名改成“某制造企业”，把精确金额改成范围，把合同原文改成规则摘要。不要输入个人信息、客户记录、薪酬、医疗信息、账号、密钥、未公开财务信息或当前正式审批材料。
