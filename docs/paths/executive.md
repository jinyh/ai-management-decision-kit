# 管理者与投资决策路径

适合总经理、董事长、副总经理、投资负责人和业务负责人。

## 建议顺序

1. [任务与经营结果](../cards/01-task-and-outcome.md)：把“做AI”改写成一个经营任务。
2. [错误代价](../cards/03-error-cost-and-evaluation.md)：比较漏报、误报、人工处理和完整成本。
3. [四层评测](../cards/10-four-layer-evaluation.md)：确认上线证据覆盖任务、经营和控制结果。
4. [建设方式与FDE](../cards/11-build-buy-and-fde.md)：选择买产品、联合实施或自建。
5. [证据门与备忘录](../cards/12-evidence-gates-and-memo.md)：只批准能够解决当前不确定性的下一阶段。

## 完成标志

能够用一页说明：为什么做、现在知道什么、还不知道什么、下一笔资源买什么证据、什么情形停止。

建议命令：`/challenge 你的AI投资方案`，然后使用[投资决策备忘录](../../templates/investment-memo.md)。
